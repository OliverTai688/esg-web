品牌故事

 

從一個泰雅族名字開始

創辦人 Evvon 在擔任社工期間，遇到了一位泰雅族的牧師。

牧師給了他一個泰雅族名字——Sayun，意思是「橋樑」。有資源的人與沒有資源的人之間，需要有一座溝通橋梁。

 

這個名字，後來成為他創業最核心的理念。

從社工到創業，Evvon 一直在尋找自己與環境互動的方式。一個機構能影響的人有限，但如果能從一個機構的影響力擴散到整個產業，改變就有機會真正發生。

如同品牌名稱「共好玟化」所承載的——共好，讓每一個加入的人，都能一起好。

 

 

價值觀

 

共好玟化的價值排序是：社會、商業、環境。

永續是環境、社會、經濟三個效益共同構成的系統。

人與人之間的關係緊密，社會才有韌性；當社會有韌性，商業才能長久運作；當商業可行，我們才有能力照顧環境。

所以共好玟化將社會放在最前面是因為：永續的核心是「人」，人與人之間共好，才能真正發揮影響力。

 

 

長期願景

 

三年後，共好玟化希望成為一個更完整的供應鏈上下游媒合平台——透過合作案例及服務指標（如白皮書、品質服務標準），讓每一次的媒合都能有依據、成果，成為可以持續深化的合作關係。
