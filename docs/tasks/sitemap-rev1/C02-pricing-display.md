## 背景

客戶擔心網站上的價格被拿來議價，要求只顯示每項服務的最高價，不要出現最低價或價格區間的下限。

## 現況：全站所有價格字串

全站沒有「起」價；唯一的價格區間是商創師培訓。

合作洽詢頁與 `courses.ts` 各自存了一份同樣的價格，改一邊不會影響另一邊。

## 要做的事

1. 向客戶取得每項服務要顯示的「最高價」。現有數字可能是基本價（例如白皮書「精華版」NT$100,000 很可能不是最高價）。
2. `consulting/page.tsx:45` 的區間改為單一最高價（依現有資料是 NT$25,000，待客戶確認）。
3. 價格只存一份：合作洽詢頁的方案卡改為引用 `src/data/courses.ts` 的價格（以 slug 對應），不要再各存一份。
4. 檢查 `/events` 的課程卡與詳情頁是否也要套用同一規則，並統一更新。
5. 已結束活動（問卷設計工作坊 NT$1,600）不再顯示價格。

## 驗收條件

- 全站沒有價格區間或「起」字樣；每項服務只有一個價格，且為客戶確認的最高價。
- 合作洽詢頁與活動頁的同一項服務價格一致，且來自同一份資料。
- `grep -rn "NT\$" src content` 的結果與客戶確認的價目表逐項相符。
- `pnpm lint`、`pnpm build` 通過。

## 待確認／風險

- **需客戶提供**：顧問輔導、永續白皮書、商創師培訓（初階／進階）、工作坊的最高價。
- 會員方案的 NT$300／月、「免費」「專案報價」是否不受此規則影響（推定不受影響）。
- 若客戶其實希望改成「不公開價格，一律洽詢」，做法會變成把價格標籤換成「專案報價」，請一併確認。
- 合作洽詢頁寫「半日工作坊」（`consulting/page.tsx:55`），`courses.ts:65` 寫「2 小時」，同一個產品的描述不一致，合併資料來源時一起修正。
