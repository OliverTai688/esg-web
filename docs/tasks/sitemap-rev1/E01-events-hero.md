## 背景

客戶要求移除 Hero 上的「2026活動季」徽章，數字改成「活動超過 150+」「合作品牌 50+」兩項。

## 現況

- 徽章：`src/app/[locale]/events/page.tsx:82-84`，文字來自 `eventsPage.hero.badge`（`zh.ts:411`、`en.ts:403`）。
- 數字：`events/page.tsx:95-106` 逐筆輸出 `eventsPage.hero.stats`（`zh.ts:414-418`、`en.ts:406-410`）。目前三筆：50+ 場活動舉辦／500+ 累計參與者／30+ 合作品牌。
- 類似的舊數字也出現在加入我們頁：`joinPage.community.metrics`（`zh.ts:609-614`：500+ 社群夥伴／30+ 合作品牌／50+ 場活動舉辦／8+ 國際論壇曝光）。

## 要做的事

1. 刪除 `events/page.tsx:82-84` 的徽章與辭典鍵 `eventsPage.hero.badge`（zh／en）。
2. `eventsPage.hero.stats` 改為兩筆：`150+ 活動舉辦`、`50+ 合作品牌`（zh／en）。排版是 flex-wrap，兩筆不需改 TSX，確認置中即可。
3. `joinPage.community.metrics` 的「場活動舉辦」改 150+、「合作品牌」改 50+，避免兩頁互相矛盾。

## 驗收條件

- `/zh/events` Hero 沒有「2026 活動季」，只顯示 150+ 與 50+ 兩個數字。
- `/zh/join` 的社群數字與之一致。
- `pnpm lint`、`pnpm build` 通過。

## 待確認／風險

- 原本的「500+ 累計參與者」客戶沒有列入新數字，本任務視為移除。E03 的時間軸文案有「培力逾 500 人」，兩者不衝突。
- 加入我們頁的「500+ 社群夥伴」是否保留，請客戶確認。
