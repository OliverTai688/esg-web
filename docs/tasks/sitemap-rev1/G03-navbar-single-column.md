| 項目 | 內容 |
|---|---|
| 階段 | Phase 1 做單欄化；Phase 2 隨各頁新區塊補項目 |
| 類型 | TSX 重構 + 辭典 |

| 相依 | S02、S03、E02、E03 完成後各自回來補／改選單項目 |
| 需求來源 | PDF p.2「navbar 分頁調整：只要一欄，並且要依序頁面排序」、p.20「新增『顧問諮詢與訂閱方案』的選項欄」、p.28「navbar 單欄依順序就好」 |

## 背景

桌機的下拉選單現在是兩欄的大面板，每欄有一個分類小標。客戶覺得不好找，要求只留一欄，項目順序跟頁面由上到下的區塊順序一致。另外永續足跡的選單要多一項「顧問諮詢與訂閱方案」。

## 現況

`src/components/domain/Navbar.tsx`（836 行，client component）：

- 選單資料：`navGroups`，在 `useMemo` 內組成（`:472-556`）。項目標題與說明來自辭典 `nav.<group>.<key>`／`<key>Desc`；欄位小標、連結與錨點、圖示都寫死在陣列裡。
- 欄位小標是寫死的中文（`:478, 485, 498, 505, 518, 526, 540, 548`），英文版也顯示中文。
- 桌機面板固定尺寸 `w-[840px] h-[400px]`（`:319`），每欄 `w-[280px]`（`:341-348`），兩欄只佔 560px。
- 桌機只有 hover 會開選單（`:595-596`），沒有點擊或鍵盤操作，頂層文字也不是連結；觸控筆電與 1024px 以上的平板打不開。
- 手機版已經是單欄（`:754` 把兩欄攤平）。
- labels 的型別是手動重複定義的（`:60-116`），新增辭典鍵時這裡也要加。
- 死碼：`MegaMenuItem`（`:204-237`）、`xOffset` prop、`src/components/ui/navigation-menu.tsx`。
- 全站沒有 `scroll-mt`，header 是 sticky 60px，錨點落點會被蓋住。

目前各選單項目與頁面順序的對照：

| 選單 | 目前順序 | 頁面實際順序 | 是否一致 |
|---|---|---|---|
| 共好永續力 | 願景與使命 `#methodology` → 共好生態圈 `#ecosystem` → 服務項目 `#services` → 共好實踐 `#impact` | services → impact → methodology → ecosystem | **不一致** |
| 永續足跡 | 活動列表 → 永續工作坊 `#workshops` → 過往回顧 `#history` → 案例研究 `#cases` | upcoming → workshops → services → history → cases | 一致，但缺 `#services` |
| 共好學習 | 創新策略 → 市場競爭力 → 永續責任 → 合作模式 → 溝通與換位思考 → 人物專訪 | 相同 | 一致 |
| 合作洽詢 | ESG 解決方案 → 非營利合作 → 會員機制 → 常見問答 → 聯絡表單 | 相同 | 一致 |

## 要做的事

**第一階段（Phase 1）**

1. 把選單資料抽到 `src/lib/nav.ts`：每個群組是一個有序陣列 `{ key, href, icon }`，不再有欄位（columns）的概念。之後其他任務新增區塊時只改這一個檔。
2. 桌機下拉改為單欄清單：寬度約 320px、高度隨內容，定位在對應的頂層項目正下方。移除欄位小標（順便解決寫死中文的問題）。
3. 順序改為頁面順序。共好永續力暫時為：服務項目 → 共好實踐 → 願景與使命 → 共好生態圈（S02 完成後會再調整）。
4. 永續足跡新增「顧問諮詢與訂閱方案」→ `/events#services`；新增辭典鍵 `nav.events.services`／`servicesDesc`（zh／en），並補上 `Navbar.tsx:74-84` 的型別。「活動列表」的連結改為 `/events#upcoming`。
5. 可及性：頂層項目可用點擊與鍵盤（Enter／空白鍵開啟、Esc 關閉、方向鍵或 Tab 移動），並保留 hover。頂層文字本身可連到該頁。
6. 錨點偏移：在 `globals.css` 對有 id 的區塊統一設定 `scroll-margin-top`（約 80px）。
7. labels 型別改為直接引用 `Dictionary["nav"]`，不要手動重複定義。
8. 刪除死碼：`MegaMenuItem`、`xOffset`、`ui/navigation-menu.tsx`（確認無引用）。

**第二階段（各頁結構任務完成後）**

9. 依最終頁面結構更新 `src/lib/nav.ts`。預計結果：

   | 選單 | 預計項目（依頁面順序） |
   |---|---|
   | 共好永續力 | 願景與使命 `#vision` → 核心價值 `#values` → 我們怎麼做 `#approach` → 雙效益理論 `#methodology` → 服務項目 `#services` → 實際成果 `#impact` → 共好生態圈 `#ecosystem` |
   | 永續足跡 | 近期活動 `#upcoming` → 永續學習地圖 `#workshops` → 顧問諮詢與訂閱方案 `#services` → 我們走過的路 `#history` → 發展藍圖 `#roadmap` → 合作案例 `#cases` |
   | 共好學習 | 維持六項 |
   | 合作洽詢 | 維持五項 |

## 驗收條件

- 桌機四個下拉選單都是單欄，項目順序與該頁由上到下的區塊順序一致。
- 永續足跡選單有「顧問諮詢與訂閱方案」，點擊後捲到該區塊。
- 點任何錨點項目，區塊標題不會被 header 遮住。
- 只用鍵盤可以開啟選單、選擇項目、關閉選單。
- `/en` 選單內沒有中文殘留。
- 手機選單行為不變。
- `pnpm lint`、`pnpm build` 通過。

## 待確認／風險

- 共好永續力在 S02 之後會有 7 個以上的區塊，選單是否全部列出，或只列 5–6 個主要區塊，請客戶確認。
- 單欄後每個項目是否保留說明小字（目前有），建議保留但縮短。
- `Navbar.tsx` 很長且動畫邏輯集中，重構時建議順便拆檔（桌機選單、手機選單、資料），降低之後修改的風險。
