#### 案例一｜大古鑄鐵 TaKu
封面圖：[https://www.taku-art.com/archive/images/news/1762155507588.jpg](https://www.taku-art.com/archive/images/news/1762155507588.jpg) （大古官網永續專區的白皮書主視覺，1920×966）。案例內文配圖建議用「修而不丟」數據頁 [https://www.taku-art.com/archive/images/editor/news/taku_25@1920px.jpg](https://www.taku-art.com/archive/images/editor/news/taku_25@1920px.jpg) 。
一句話：把「修而不丟」算成碳與生意。
產業：消費品牌／鑄鐵鍋具與生活器物
挑戰
鑄鐵是高耗能材質，談永續很容易被質疑。大古想說清楚：一口能用一輩子的鍋，對環境的意義到底是什麼？
我們怎麼做
共好玟化陪大古把產品放回完整生命週期來看：不比重量、改比同體積的材料碳排，再攤到使用年限，結論是「越能長久相伴的東西，對環境越溫柔」。數據只算原料到製造階段、不假設理想情境、來源全部公開。同時把既有的「回娘家」維修計畫整理成可量化的循環成果，並寫成合作夥伴專章，讓企業與零售通路知道能怎麼一起做。
成果
・回娘家計畫維修 136 件，延壽鐵料 248.4 kg，相當於避免新製 0.55 噸 CO₂e
・參與顧客再購率 68%、滿意度 4.8／5
・大古在官網設立「永續生活 ESG」專區，全本白皮書公開上網，並把內容轉成社群貼文持續分享
延伸閱讀：大古鑄鐵官網永續專區 [https://www.taku-art.com/news/esg_life](https://www.taku-art.com/news/esg_life)
