# 思凡自然農園社會性農場

**URL：** https://coesg.tw/courses/selvanssocialfarm
**擷取日期：** 2026-04-11
**講師：** ESG共學坊

## 課程描述

這是一個結合農業、社會福祉與環境永續的社會企業倡議。該組織致力於建立「跨界合作的社會性農場系統」，透過三大核心方法：社福契作支持、企業永續採購連結，以及教育與療癒設計，實現農業與社會行動的融合。

## 課程目標

- 建立社福機構的農業收入來源
- 提供身心障礙者「準備性就業」機會
- 協助企業實現ESG社會責任目標
- 打造融合感官統合與自然體驗的教育空間

消費者享有貨到7天猶豫期，食品類商品需「保持全新未拆封狀態」方可退換；瑕疵品另行處理。退款作業於確認後7-14個工作日內完成。
