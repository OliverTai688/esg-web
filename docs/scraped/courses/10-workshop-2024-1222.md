# 問卷設計實作工作坊

**URL：** https://coesg.tw/courses/workshop-2024-1222
**擷取日期：** 2026-04-11
**講師：** 吳玟樺（共好玟化組織發展顧問有限公司 創辦人）

## 課程描述

本工作坊針對永續發展領域的專業人士設計，時長2小時。聚焦於解決三大核心問題：
- 如何透過問卷精確了解利害關係人的永續發展觀點
- 提升問卷回應率
- 強化問卷設計的精準度以支持企業永續目標

## 課程核心內容

1. **4W目標設定法** — 釐清問卷目的與目標受眾
2. **薩提爾冰山理論** — 優化問卷邏輯與問題順序
3. **模板實作練習** — 透過互動演練打造客製化問卷
