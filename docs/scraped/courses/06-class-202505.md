# 永續品牌初階工作坊

**URL：** https://coesg.tw/courses/class-202505
**擷取日期：** 2026-04-11
**講師：** 吳玟樺（共好玟化組織發展顧問有限公司 創辦人）

## 課程描述

用2小時掌握打造永續品牌的第一步。課程採互動式教學模式，幫助學員建立永續品牌的基礎觀念與核心價值。透過實作工具與真實案例分享，參與者將能夠思考品牌與永續議題之間的連結方式。

## 適合對象

- 初次接觸永續議題的品牌經營者
- 企業團隊成員
- 創業者

- 組織領導團隊教練
