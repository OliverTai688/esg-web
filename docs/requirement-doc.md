# 一、專案背景與合作目標

本次網站建置專案由 圓展教育科技有限公司（以下簡稱「圓展」）協助合作夥伴建立永續品牌網站。

專案旨在：

* 透過完整的網站規劃與設計，強化品牌理念的呈現
* 建構具備可擴張性、可維護性、高一致性的網站基礎
* 為後續品牌推廣、教育內容、活動宣傳奠定穩固的數位架構

本需求書作為 啟動專案與第一期款項付款依據，雙方確認需求後即可開始啟動流程。

二、網站建置服務範圍

本專案第一階段建置內容如下：

### 1. 資訊架構規劃（Information Architecture）

* 進行網站整體頁面地圖（Sitemap）
* 使用者導覽流程（User Flow）規劃
* 內容區塊配置與層次架構

### 2. 品牌視覺設計與 Figma UI 設計

* 桌機版與手機版版面設計
* 風格統一的設計系統（Design System）
* Figma 原型（Prototype）互動展示
* 含 2 次修正（不含架構大幅變更）

### 3. 前端網站開發（Next.js + Tailwind CSS）

* 採用最新 Next.js＋App Router 架構
* Tailwind CSS 視覺切版
* RWD 響應式設計
* 行銷頁面、品牌頁面、導覽列、頁尾、介紹頁等基本頁面

### 4. 中英文語系切換模組（i18n System）

* 語系切換（EN / 中文）
* 語系路由設定
* 文案管理模組（支援後續更新）

### 5. 部署與 SEO 設定

* 部署至 Cloudflare / Vercel
* 基本 SEO 設定：關鍵字標籤、Open Graph、結構化資料
* 與客戶協作完成網域設定

三、可交付項目（Deliverables）

本階段完成後，圓展將交付以下項目：

1. 完整的 Figma 設計稿（Desktop / Mobile）
2. Next.js 完整網站程式碼（含 RWD）
3. i18n 語系切換模組
4. 已部署之正式網站（含 Cloudflare / Vercel 設定）
5. 基本 SEO 完成設定
6. 1 年內基本維護（錯誤修正、小幅調整）

四、不包含內容

本需求書範圍 不包含電商平台功能，如：

* 商品銷售
* 購物車
* 線上付款

若未來須加入商品銷售系統，雙方將以「平台分潤型合作」模式進行延伸協議。

五、專案時程

預估開發時程為 8–10 週（取決於回饋速度與內容提供時間）。

# 附件二、首頁Landing Page 設計說明

參考訪談資料進行整理

本文件依據「永續品牌 Landing Page 訪談文件」之實際訪談內容整理，將訪談所蒐集之品牌定位、品牌故事、永續行動、商業模式與合作需求轉換為網站首頁（Landing Page）之資訊架構與內容策略。

此設計目的在於將品牌理念與產業角色轉化為清晰且具有商業轉換能力的首頁敘事，使訪客能在短時間內理解品牌定位、產業價值與合作可能性。首頁將同時服務三個核心目標：

第一，建立品牌作為「產業橋樑」的核心定位，使企業與品牌方能快速理解品牌存在的意義。
第二，透過品牌故事與永續行動證據建立可信度，讓訪客理解品牌的社會使命與產業角色。
第三，透過清晰的行動轉換設計，引導企業採購方、品牌方與合作夥伴進入合作洽談流程。

整體設計採用敘事式資訊結構，使訪客在瀏覽過程中逐步建立理解與信任，並最終產生合作行動。

---

# 一、Landing Page 整體敘事架構

首頁資訊架構將依照訪客理解流程進行設計，透過逐步敘事使訪客從認識品牌到理解產業問題，再到建立信任與合作行動。

| 區塊               | 內容目的               | 對應訪談內容      |
| ------------------ | ---------------------- | ----------------- |
| Hero 區            | 傳達品牌核心主張       | 一句話定位        |
| Brand Story        | 建立品牌故事與理念     | 創立契機          |
| Problem / Solution | 說明產業問題與品牌角色 | 主要解決問題      |
| Impact / Evidence  | 展示永續行動與成果     | 永續行動          |
| Future             | 說明平台未來發展       | 長期願景          |
| Trust              | 建立可信證據           | ESG / 媒體 / 客戶 |
| CTA                | 引導合作行動           | 合作方式          |

此架構將確保訪客能逐步理解品牌角色與合作價值。

# 二、Hero 區（品牌主張）

Hero 區為首頁最重要的資訊區塊，其主要目的為在訪客進入網站後的數秒內，清楚傳達品牌定位與產業角色。

訪談結果顯示，品牌的核心定位是作為不同產業與資源之間的專業橋樑，使企業能夠理解供應鏈中的品牌價值，並促進企業採購與品牌合作。品牌希望建立一個讓下游廠商能夠被看見的平台，並讓企業能更容易找到適合的合作夥伴。

此區塊將呈現品牌的一句話定位與核心主張。

| 設計元素 | 內容                     |
| -------- | ------------------------ |
| 品牌定位 | 點亮你獨特的專業價值     |
| 核心概念 | 建立企業與品牌之間的橋樑 |
| 主要行動 | 預約 15 分鐘 Coffee Chat |
| 次要行動 | 查看案例或商城           |

Hero 區的設計將透過簡潔文字與視覺呈現供應鏈連結概念，使訪客快速理解品牌價值。

# 三、Brand Story 區（品牌故事）

品牌故事區主要用於建立情感信任與品牌可信度。訪談內容顯示，品牌創立背景具有重要敘事價值。

品牌創辦人曾從事社會工作，在工作過程中接觸到泰雅族牧師，並受到啟發，將品牌命名為「Sayun」。此名稱象徵橋樑與引導者的角色，代表希望在有資源與缺乏資源的群體之間建立連結。

創辦人從社工轉向創業的過程，源自對自身使命與社會角色的思考，希望透過過去的經驗建立更大範圍的影響力，從單一機構的服務延伸到整個產業的連結。

| 敘事元素   | 內容                     |
| ---------- | ------------------------ |
| 創立契機   | 社工背景與泰雅族文化啟發 |
| 品牌名稱   | Sayun，象徵橋樑與引導    |
| 創辦人使命 | 建立資源與價值的連結     |
| 社會角色   | 從機構服務延伸至產業橋接 |

此區塊將透過故事敘事與文化元素建立品牌深度與信任。

# 四、Problem / Solution 區（產業問題與解決方案）

訪談顯示，目前產業在永續供應鏈與品牌合作上存在明顯資訊落差。許多企業難以理解市場中的品牌地圖，也難以找到適合合作的供應鏈夥伴。同時，許多具有理念與品質的小型品牌缺乏進入企業採購體系的機會。

品牌希望透過專業媒合與資訊整合，建立一個能夠揭露供應鏈地圖並促進合作的平台。

| 產業問題   | 說明               |
| ---------- | ------------------ |
| 品牌方痛點 | 不清楚企業合作入口 |
| 企業痛點   | 難找到可信供應鏈   |
| 產業問題   | 供應鏈資訊缺乏透明 |
| 環境問題   | 永續理念難以落地   |

| 解決方案   | 說明               |
| ---------- | ------------------ |
| 供應鏈地圖 | 揭露產業關係       |
| 媒合平台   | 建立企業與品牌連結 |
| 案例展示   | 提供合作案例       |
| 資訊整合   | 提供永續與產業資訊 |

此區塊將透過問題與解決方案的對照，使訪客理解品牌存在的必要性。
