## 一、先講結論

1. **選單與區塊已經對齊。** 導覽列下拉、頁內章節膠囊、頁面區塊現在讀同一份清單（各頁辭典的 `chapters`）。`node scripts/check-anchors.mjs` 為 0 錯誤、0 警告；四個下拉選單共 21 個頁內項目逐一實測，全部落在對應區塊、小標與選單同名、章節膠囊亮在同一顆。
2. **文字密度全部在預算內**，降幅 23%–70%（見第二節）。客戶文案沒有刪除，超出的部分移到分頁籤、可展開列或「展開全文」，仍在 HTML 裡。
3. **接下來最值得做的三件事都不是版面**：
   - 沒有任何流量分析工具，導流成效目前無法量測（第四節 G1）。
   - 聯絡表單沒有後端，訪客沒有郵件軟體就送不出去，是轉換頁最大的漏點（G2）。
   - 多處內容仍是暫定值或待授權：價格、質化成果、顧問姓名、案例照片（G3）。

### 4. 驗收做了什麼、沒做什麼

**做了，而且通過**
- 型別檢查、ESLint（`src`、`scripts`）、用語檢查、`next build`（127 個靜態頁）。
- `check-anchors`：0 錯誤、0 警告（含全站跨頁 `#錨點` 連結）。
- 22 個網址（11 條路由 × 中英）在 375px 與 1280px：無水平捲動、每頁一個 `h1`、`<main>` 內沒有小於 44px 的可點擊目標。**唯一例外是首頁**（見 G6）。
- 四個下拉選單的頁內項目逐一點擊（1280px）：落點、小標、亮燈都正確；跨頁項目抽測一項（從 `/join` 點「永續足跡 → 發展藍圖」）正確。
- 32 份提案檔實際開啟：每份 3 案、密度徽章正常；修掉一份在 375px 切換下的欄寬溢出。
- 各頁桌機逐區塊截圖檢視；手機檢視了 `/sustainability`、`/events`、`/learning`、`/consulting` 的重點區塊。

**沒做，或只做了一部分**
- **捲動與載入動畫的實際效果沒有看到。** 驗收用的瀏覽器面板在背景執行，平滑捲動與動畫不會跑；落點是關掉平滑捲動後量的，動畫只看到靜止狀態。上線前請用一般瀏覽器走一次。
- 真機、Safari／Firefox、螢幕閱讀器、只用鍵盤的完整操作、`prefers-reduced-motion`、關閉 JavaScript：都沒有測。
- 英文版只做了自動檢查（不破版、不溢出）與少數截圖，沒有逐區塊看過；新增字串的英文是暫譯。
- 手機版 `/insights`、`/join`、文章頁、主題頁只有自動檢查與各組自己的截圖，主線沒有再逐區塊看。
- 表單沒有實際送出，LINE 連結沒有實際開啟。

## 五、建議的下一步順序

1. **向客戶一次問完**（G3、各頁標「卡在客戶」的項目）：價格、質化成果、顧問授權、學習地圖配色、訂閱結束日、精選文章規則、照片。這些決定會改到五個頁面的內容。

3. **決定表單與 LINE 的做法**（G2），接著把「收尾 → 表單」「案例 → 表單」「候補 → LINE」這幾條路接上情境。

5. **分頁籤網址直達**（G4），再把跨頁的服務連結改成直達對應方案。
6. **把首頁拉回同一套規則**（G6）。
