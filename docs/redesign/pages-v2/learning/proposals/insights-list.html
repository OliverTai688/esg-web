優點

  • 三層閱讀清楚：頭條（3 秒）→ 近期四篇（20 秒）→ 月份（主動展開）。

  • 16 篇標題都在 HTML 裡（原生 <details>），文章再多，頁面長度也不變。
  • 最後一段把人送回主題：六片花瓣各自連到 /learning 的那個主題。

  • 近期五篇在月份列裡會再出現一次（月份列是完整索引，接受重複）。
