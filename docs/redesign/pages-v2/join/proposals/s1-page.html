如何加入

三步驟，成為共好夥伴

  1. 掃碼加入

    掃描 QR Code 或點擊按鈕，加入共好玟化 LINE 官方帳號。

  2. 接收資訊

    開始接收永續趨勢、活動通知與合作機會等第一手訊息。

  3. 參與互動

    報名活動、回覆訊息、加入討論，成為永續生態圈的一份子。

優點

  • 環貫穿三段：花瓣圍成一圈（入口）→ 切成四段（四個好處）→ 一段一段閉合（三步驟）。首頁的拱在這裡變成完整的圈。
  • 桌機第一屏就能掃 QR；手機第一屏是按鈕。收尾再給一次同一顆按鈕。
  • 四個好處的說明都看得到（這是加入的理由）；被收合的只有重複按鈕文字的步驟說明。

風險

  • 四格中心的環只在桌機成立；手機改成每張卡一段弧。
  • 花瓣環要用 SVG 算座標（首頁已有）。

與前後區塊的銜接

  • Hero → 加入好處：花瓣環最下面的一片落在交界（T1）。
  • 加入好處 → 如何加入：大環縮成三個小環（T10）；收尾的環捲入時描邊（本頁唯一的捲動動畫）。

優點

  • 字數最少；桌機上 LINE 卡全程跟著捲動，行動永遠在視線內。
  • 整頁只有一個區塊，最短。

風險

  • 手機沒有左右欄：卡片排在最上面時，訪客還不知道這是什麼就先看到 QR（手機上掃不了自己螢幕上的 QR）；排在下面則黏著失效。
  • 好處的說明被收合——加入的理由要點四次才讀完。
  • 沒有環：這一頁的主角形狀沒有出現，和其他內容頁看不出差別。
