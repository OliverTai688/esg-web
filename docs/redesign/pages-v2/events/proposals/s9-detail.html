優點

  • 第一屏（手機也是）就回答三件事：這是什麼課、現在的狀態（虛線圓＝還沒排定）、我能做什麼（LINE 候補）。
  • 回上一層的連結寫出章節名稱，回到它所屬的區塊：課程 → 下一梯次、服務 → 持續服務、已結束 → 我們走過的路。
  • 下一步的順序符合跨頁規劃：LINE 第一、學習地圖第二；已結束的活動也有下一步（收開課通知）。

風險

  • 桌機沒有固定在側邊的按鈕：頁面只有一屏半，按鈕在第一屏，可接受。
  • 事實列手機兩欄，講師名稱 12 個字會換行。

與 /events 的銜接

  • 「下一梯次」的列 → 本頁：小虛線圓放大成本頁的大虛線圓。
  • 本頁 → 回程：落在所屬章節的小標；或往前走到學習地圖。
