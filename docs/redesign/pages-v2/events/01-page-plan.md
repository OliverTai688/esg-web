## 二、一句話

**這一頁是橋面上的腳步。** 首頁把橋搭起來；這一頁讓訪客看見橋上已經有人在走——每一個圓是一步：還沒落地的下一步、可以自己選的八步、走過的十五步、接下來要走的三段路、別人和我們一起踏出的那一步。

訪客要帶走的順序：**現在能參加什麼 → 走過哪裡 → 要去哪裡 → 換你踏上來。**

## 三、主角形狀：圓（disc）與它的零件

只用首頁形狀文法裡的圓、半圓、四分圓；變形只用縮放、換色、旋轉 90° 倍數、鏡射、重組。

| 狀態 | 畫法 | 意義 |
|---|---|---|
| 虛線圓 | 圓＋虛線外框、無填色 | 還沒落地的一步（規劃中） |
| 實心圓 | `Disc` | 已經踏出的一步（里程碑、已結束的活動） |
| 一列小圓 | 1 顆／4 顆／8 顆 | 走多遠：一次、一段、持續 |
| 逐漸變大的圓 | 同一個圓、依年份放大 | 累積 |
| 四分圓 → 半圓 → 圓 | `Quarter` → `Half` → `Disc` | 還要走的路：近程、中程、遠程（與首頁藍圖同一組形狀，跨頁接力） |
| 兩個半圓合成一個圓 | 兩個 `Half` 旋轉 ±90° 相接 | 兩個夥伴的一步合在一起（合作案例） |

色彩角色沿用全站：橘＝共好玟化與主要行動、黃＝夥伴與重點底色、冷灰＝企業端與資料。學習地圖的四個層次色（`level-blue/green/yellow/red`）只出現在學習地圖，而且一定附層次名稱文字（E02）。

完整火焰兩次：Hero（走在路上的那個人）、收尾 `CtaBand`。

## 九、課程詳情頁 `/events/[slug]`

- **定位**：一個足跡的近照。訪客多半從 LINE 推播或海報直接落地，帶著「這堂課是什麼、怎麼報名」。
- **形狀**：一個大圓，狀態跟著課程走——規劃中＝虛線圓（與 `/events` S2 同一個圓，跨頁接力）；可預約／開放中＝橘色實心圓；已結束＝冷灰實心圓。課程重點是圓下方的一列編號小圓。
- **底色**：Hero 改為淺色（不比 `/events` 重）；不使用深色段與完整火焰。
- **回上一層**：回到它所屬的章節，不是頁面頂端——課程 → `/events#upcoming`、顧問與訂閱 → `/events#services`、已結束 → `/events#history`。連結文字帶章節名稱（「返回 下一梯次」）。
- **下一步**：主＝LINE（規劃中：候補下一梯次；服務：洽詢；已結束：收開課通知）；次＝看永續學習地圖（`/events#workshops`）。已結束的活動不顯示價格（C02），但仍給下一步。
- **字數**：≤ 260（現況 227）。
- **誠實**：規劃中的課程日期欄寫「下一梯次規劃中」，全頁不出現「報名」按鈕文字。
