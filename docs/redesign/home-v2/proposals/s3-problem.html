我們在解決什麼：三個問題，一個答案

文案的結構本身就是「3＋1」：三個層次的痛點（品牌主、產業、國際），加上一個答案與四個支柱。三個方案都用幾何變換把「3 → 1」畫出來：四分圓拼成圓、三條色帶合為一條、三片花瓣轉成四瓣花。

本頁僅呈現選項，不做推薦；取捨將依首頁總體規劃另行決定。

我們的答案

成為永續生態圈的專業橋樑

共好玟化透過顧問輔導、永續白皮書服務、ESG共學坊與溝通平台，讓不同領域的永續價值能被企業理解、被市場看見、也能找到理念相符的合作夥伴。說清楚，才能被看見。

  • 顧問輔導
  • 永續白皮書
  • ESG共學坊
  • 溝通平台

概念

「三個缺口＋一個答案，才是一個完整的圓」。桌機版 2×2 格，每格在內角放一片四分圓，四片在格線交點拼成一個圓、圓心是白色火焰；手機版每張卡左上角是一片「碎片」，到了解方卡才看到四片拼好的完整圓。

幾何語彙與變換

  • quarter ×4、disc、標誌
  • 旋轉：同一片 quarter 旋轉 0/90/270/180° 放入四個內角
  • 重組：4 quarter → 1 disc（解方＝補上最後一塊）
  • 換色：橘／黃／灰三痛點，解方回到橘
  • 支援的瀏覽器中，捲動時四片由外向內滑入合體（scroll-driven）

參考來源

Apple「環境」頁與 Stripe「Payments」頁的 2×2 特色格；Pentagram 為 MIT Media Lab 所做的格狀識別（同一形狀在格內旋轉變化）。

優點

  • 「3＋1」的文案結構被圖形直接說明，不需額外說明文字
  • 解方與痛點同處一格，比例對等，不會被當作頁尾附註
  • 桌機合體、手機分片，兩種尺寸都各自成立

風險

  • 內角留給四分圓的空間讓每格變高，桌機區塊總高度約 900px
  • 若 S1 也採用四分圓組裝，兩區重複度高，需擇一或做出差異

與前後區塊的銜接可能

  • ① 承接 S2：夥伴牆最後一塊幾何磚（四分圓）放大後「落」到本區左上角，成為第一片碎片。
  • ② 銜接 S4：中心的白色火焰標誌往下延伸成故事區的「Sayun」起點，圓形放大為故事區背景的同心圓。

概念

「問題是有層次的」。文案明說「三個層次」：品牌主 → 產業 → 國際，範圍一層比一層大。三條 CIS 色帶的長度依序放大（約 40%→70%→100%），像一座逐級變寬的階梯；到了解方，三條色帶首尾相接合成一條，帶出「同一座橋」。

幾何語彙與變換

  • block 色帶＋half 圓頭（膠囊端）、四支柱各配 quarter／half／petal／disc
  • 縮放：同一色帶 scaleX 0.42／0.7／1
  • 重組：三條 → 一條多色分段帶
  • 支援的瀏覽器中，捲動時色帶由短長到定位

參考來源

Patagonia、Ørsted 永續報告網頁的「層級遞進」敘事；The Pudding 與 Bloomberg 圖表式網頁中以長條比例表達範圍的手法。

優點

  • 最貼近文案原意（三個層次），閱讀順序與範圍大小一致
  • 色帶可直接作為後續頁面的分類色（黃＝品牌主、橘＝產業、灰＝國際）
  • 純排版＋色塊，實作最簡單、最穩定

風險

  • 長條容易被誤讀為「資料圖表」（例如比例或成長）
  • logo 筆觸元素在本方案較少，品牌圖形感相對弱

與前後區塊的銜接可能

  • ① 承接 S1 的三色橋（若採用超大火焰方案）：Hero 的黃／橘／灰三塊直接延伸成本區的三條色帶。
  • ② 銜接 S4：底部合併後的多色細帶留在頁面上，成為故事區的頂部邊界，象徵「把橋接起來」。

顧問輔導永續白皮書ESG共學坊溝通平台

概念

「同一個標誌，三個面向」。左側轉盤上有三片花瓣（三個層次），讀到哪一張卡，轉盤就轉 120° 把對應的花瓣轉到指針下並點亮；三張卡讀完，到了解方區，花瓣重新排成 90° 間隔的四瓣花，對應四個支柱。

幾何語彙與變換

  • petal、虛線 ring、tri 指針、標誌
  • 旋轉：轉盤每步 −120°
  • 放大：當前花瓣外移並放大 1.18 倍
  • 重組：3 瓣（120° 間隔）→ 4 瓣（90° 間隔）
  • 卡片圖示保留各自花瓣的角度（0／120／240°）

參考來源

Apple 產品頁的「sticky 圖像＋捲動文字」敘事（scrollytelling）；Stripe Atlas、Linear 功能頁中隨段落切換的固定插圖。

優點

  • 最有「互動感」，捲動本身就是在轉動品牌標誌
  • 文字全部以卡片完整呈現，動畫只是加分，不會擋住內容
  • 解方的四瓣花可延伸為四個服務的圖示系統

風險

  • 需少量 JavaScript（IntersectionObserver）切換轉盤狀態；關閉 JS 時轉盤停在第一步
  • 手機版轉盤無法固定在側邊，敘事效果減弱為一般卡片列表
  • sticky 版面在內容很短時效果不明顯

與前後區塊的銜接可能

  • ① 承接 S2 花瓣成環：夥伴環收合成三片花瓣，直接成為本區轉盤（同一組元素持續變形）。
  • ② 銜接 S4：四瓣花旋轉 45° 並放大，成為故事區四點信念（bullets）的編號圖示。
