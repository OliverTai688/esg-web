夥伴：沒有 logo 也能有份量的信任列

目前夥伴 logo 檔與露出授權仍在確認中（H01），因此三個方案都只用「名稱」排版，並以三種幾何形分別代表三個群組：品牌與企業、公部門與學會、非營利與國際。日後取得 logo 時可直接替換名稱。

本頁僅呈現選項，不做推薦；取捨將依首頁總體規劃另行決定。名單與分組完全取自現行文案，未加入數量或其他主張。

概念

「每一個名字都是一塊磚」。名字以方磚排成一面牆，每塊磚左上角的小圖形依序旋轉 90°，讀過去像圖形在轉動；三個群組各有一塊實心色磚當作「章節」，牆面中穿插純幾何磚，讓整面牆本身就是一張 CIS 圖樣。

幾何語彙與變換

  • quarter＝品牌與企業、half＝公部門與學會、petal＝非營利與國際
  • 旋轉序列：同一形狀依序 0/90/180/270°
  • 換色：群組色磚中的圖形反白
  • hover 時圖形再轉 90°、磚面淡染群組色；支援的瀏覽器在捲入畫面時圖形由 −180° 轉回定位

參考來源

Stripe「Customers」頁與 Vercel 首頁的格狀 logo 牆；Studio Dumbar 為荷蘭交通部等識別所做的「形狀旋轉序列」圖樣。

優點

  • 日後換成 logo 時版型完全不變，只要替換磚內內容
  • 形狀＝群組的編碼，色盲使用者也能辨識（不只靠顏色）
  • 手機兩欄、平板四欄、桌機六欄，皆整齊收尾

風險

  • 六欄磚牆高度可觀，若放在 Hero 之後可能讓「下一個重點」被推得太遠
  • 名稱長短不一（例如英文會議名稱），磚內換行需逐一檢查

與前後區塊的銜接可能

  • ① 承接 S1 若採用模組格方案，磚牆可直接沿用同一個 --geo-unit，視覺上像 Hero 的色塊「長出」名字。
  • ② 牆的最後一塊幾何磚（灰圓＋橘四分圓）放大成 S3 的開場圖形，作為「這些夥伴遇到了什麼問題」的轉場。

概念

「三種夥伴，是同一把火焰的三片花瓣」。區塊頂端三片花瓣以 −30°／0°／30° 扇形排成一束小火焰；往下拆開成三張卡，每張卡保留自己那片花瓣的角度，hover 時花瓣轉正——從「一束」到「各自」再到「對齊」。

幾何語彙與變換

  • petal（標誌筆觸）為唯一形狀，三色＝三群組
  • 拆解／重組：一束火焰 → 三張卡
  • 鏡像：中間卡片的花瓣圓角左右翻轉（0 64 0 64 → 64 0 64 0）
  • 旋轉：卡片 hover 時圖示轉正、放大
  • 卡片角落的大花瓣浮水印以 14% 透明度重複同一形狀

參考來源

Notion、Figma 客戶頁以「分類卡＋清單」呈現合作對象；Airbnb 品牌指南中以同一圓角形狀做卡片外框的作法。

優點

  • 資訊結構最清楚，三個群組一眼可比較
  • 整體最安靜、留白最多，適合與高度視覺化的 Hero 搭配
  • 清單是純文字，SEO 與螢幕閱讀器友善

風險

  • 三張卡長度不同（8／5／5 筆），桌機底部參差
  • 像一般「卡片清單」，若前後區塊也用卡片，記憶點會被稀釋

與前後區塊的銜接可能

  • ① 承接 S1 的火焰標誌：Hero 中的標誌縮小並「裂開」成區塊頂端的三片花瓣。
  • ② 三張卡的花瓣角度（−30／0／30）在 S3 延續為三個痛點的圖示，讓「夥伴類型」與「問題層次」用同一套形狀對應。

滑鼠移到名稱上，對應的花瓣會在圓環上被點亮。

概念

「每一位夥伴都是火焰的一片花瓣」。載入時所有花瓣先疊在頂端，再沿圓周展開，排成以標誌為圓心的花環；內圈色環依三個群組分段。名稱清單與花瓣一一對應，移到名稱上即點亮該片花瓣——讓「名單」變成「我們一起組成的圓」。

幾何語彙與變換

  • petal ×18、ring（以 conic-gradient 分段）、標誌
  • 旋轉＋放射：花瓣每 20° 一片，從一束展開成一圈
  • 重組：花瓣（火焰筆觸）→ 圓環
  • 放大：對應的花瓣在 hover 時外移並放大 1.25 倍

參考來源

Google「About」頁與 Apple 環境進度報告中的放射狀資料圖；Spotify Wrapped 的圓形構圖與互動點亮。

優點

  • 夥伴區不再只是「信任列」，而是一個可以被記住的品牌圖像
  • 花瓣數量會隨名單成長，未來新增夥伴即自然「長滿」
  • 深色底與 S1／S3 的淺色底形成節奏

風險

  • 花瓣與名單的對應需要互動才看得懂，觸控裝置上無 hover
  • 名單超過約 30 筆時花瓣會過密，需改為每片代表一個群組或分圈
  • 圓環圖可能被誤讀為「比例圖表」

與前後區塊的銜接可能

  • ① 若 S1 採用花瓣拱橋：Hero 的半圓拱在此「補完」成整圓，延續同一個放射動作。
  • ② 圓環在捲出時收合成三片花瓣，分別成為 S3 三個痛點的標記，深色底在 S3 解方帶再出現一次形成呼應。
