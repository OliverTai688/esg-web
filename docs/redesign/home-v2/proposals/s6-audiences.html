概念
桌機上三道門的門楣合起來是一座完整的圓頂：三種夥伴屬於同一個生態圈。滑過某一道門，它從圓頂中「被推開」浮起；手機上圓頂拆開，每道門各自長出完整的拱。藍圖則用「四分之一 → 半圓 → 整圓」表達逐步長成。
幾何語彙與變換
拱（half / dome）＋色塊（block）＝門；以容器寬度計算位移，讓三片門楣重組為一個橢圓頂（recombine），窄螢幕時重新拼貼為三個獨立拱（re-tile）。互動時該門上浮 12px，其他門楣降低飽和（recolour）。門楣內小圖示：花瓣／方塊／四分圓。藍圖用四分圓 → 半圓 → 整圓重組成長。
參考來源
Airbnb「成為房東」與 Mailchimp 的大色塊分流入口；Pentagram 作品中常見的「切片拼回整體」版面（如 MIT Media Lab 識別的網格切割）。
優點
分流一目了然，整張門都是點擊範圍；圓頂直接延續「Sayun 橋」的拱形；三色門讓三種夥伴有固定代表色，可延伸到內頁。手機版自然變成三張拱形卡，不需另做設計。
風險
橘門上白色標題只能用 24px 粗體，內文需用墨色，同一張卡內混用兩種文字色需細調；圓頂切片依賴容器查詢單位，舊瀏覽器會退化為三個獨立拱（可接受）；三色等重可能弱化「兩大群體＋共學坊」的主次。
與前後區塊的銜接可能
  • 可能一：證據區的圓（或拱）在接縫處被切成三片，落下成為三道門楣；離開時中間那道灰門延伸成客戶回饋區的深色底，回饋從「門後」出現。
  • 可能二：證據區以淺底收尾，這裡改用紙色＋三色門形成第一個大面積 CIS 色塊；離開時藍圖的整圓放大成為客戶回饋區中央的火焰底盤。

概念

幾何語彙與變換

參考來源

優點
最直接講出品牌名稱的意義，且不需互動即可理解；鏡像構圖讓「品牌主」與「企業」看起來對等，符合橋樑定位；白底＋細線，資訊密度高也不擁擠。
風險
文案順序是品牌主→企業→學習者，此案為了構圖把學習者放到中間（DOM 順序已調整），需確認可接受；拱的節點位置綁定三欄，若未來變四種夥伴需重算；手機版看不到完整的拱，橋的意象較弱。

  • 可能一：證據區若用拱或環，這道拱是它的延續（同一條線從上一區畫進來）；離開時橋面（深色粗線）延伸為客戶回饋區的頂邊。
  • 可能二：證據區以色塊收尾時，這裡以白底「留白呼吸」；離開時拱心火焰下降，成為客戶回饋區花瓣環繞的中心。

概念
把品牌色票本身當成選單：三種夥伴是三張 CIS 色票，像設計師手上展開的色票扇。選到哪一張，那張就從扇中抽出、轉正。藍圖是一條由淺到深的色階，越往後越飽和、越寬。
幾何語彙與變換
色票上方是 CIS 色塊與幾何（花瓣／方塊＋四分圓／雙圓）；桌機上三張以底部為軸旋轉 -6°／0°／6° 成扇形，互動時轉正＋上移；手機上改為 ±1.2° 的輕微交錯堆疊。藍圖色階以重新上色（白→黃→橘）與縮放（寬度與高度遞增、右上角四分圓半徑遞增）呈現。
參考來源
Pantone 色票扇的實體隱喻；Pitch.com 與 Arc 網站的扇形卡片堆疊互動。
優點
最有「設計品牌」的手感，色票標註直接展示 CIS 規範，對外溝通「我們有完整識別」；白卡內文對比最好；藍圖色階不需圖示就能讀出「由淺入深」。
風險
色票隱喻對非設計背景的受眾可能較難意會；扇形重疊在 900–1100px 之間較擠，需微調位移；色票上的「CIS · 165 C」是內部規格語言，正式上線時可能要換成對使用者有意義的標籤。
與前後區塊的銜接可能
  • 可能一：證據區的數字色塊在接縫處「收成一疊色票」，再在這裡展開成扇；離開時第三張黃色票放大成客戶回饋區的底色帶。
  • 可能二：以淺橘底（orange-soft）在證據區與回饋區之間形成一段暖色過渡；離開時色階最右端的大四分圓延續為回饋區左上角的裁切圖形。
