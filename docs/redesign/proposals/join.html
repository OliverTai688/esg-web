旅程位置：留存（Community）。唯一目標：一分鐘內加入官方 LINE（@381iutjm）。主要角色 P4 個人學習者、P1 品牌主；多數人從手機進來。

三案都遵守：手機上以大按鈕直接開啟 LINE App（QR 只在桌機顯示）；可複製 LINE ID 作為備案；不另外寫一份數字。

數字規則：現行頁面的 500+／50+／150+ 與首頁不一致，三案改用客戶時間軸可驗證的「100+ 場講座／500+ 人培力／10+ 縣市」（B、C），或完全不放（A）。QR Code 為占位，需由 LINE 官方帳號後台匯出正式圖檔。電子報 email 登記（J01）不在本次範圍。

提案 A

一張卡：一個按鈕，什麼都不多

概念
整頁只有一張置中卡片：標題、「約 1 分鐘」、一顆大按鈕、LINE ID 複製，下面四個好處各一行。拿掉導覽列與數字，讓注意力只剩一件事。
參考來源
Patagonia Action Works 單一行動頁、Ørsted 的「一頁只講一件事」；行動優先的活動報名頁與 App 下載頁。
優點
  • 最快完成目標，手機第一屏就有按鈕
  • 內容最少，最容易維護、不會再出現數字不一致
  • 可直接當作名片、海報 QR 的落地頁
風險
  • 對還不認識 CO-ESG 的人說服力最低
  • 拿掉主導覽後，想逛的人只能靠頁尾與「共好學習」連結
  • 版面簡單，品牌感依賴色彩與標誌
對旅程的作用
服務已經決定要加的人（從海報、講座現場、文章文末點進來），零干擾完成留存；最適合作為全站所有「加入 LINE」按鈕的共用落地頁。

提案 B

先看會收到什麼：用訊息預覽消除顧慮

概念
第一屏左邊是按鈕與數字，右邊是一支手機，示意加入後會收到的三種訊息（趨勢速報、ESG共學坊活動、新文章），內容取自真實文章標題。往下才是四個好處與三步驟，最後再給一次按鈕。
參考來源
Unilever、IKEA 電子報訂閱頁的「內容預覽」；App Store 截圖式的價值呈現；B Lab 以社群規模建立信任。
優點
  • 直接回答「會不會被洗版、值不值得加」的顧慮
  • 數字＋訊息預覽同時提供信任與具體感
  • 內容最完整，適合從搜尋或首頁第一次來的人
風險
  • 手機示意需隨推播內容更新，否則會過時
  • 頁面較長，部分人會滑過按鈕
  • 示意圖必須標明「示意」，避免被誤認為截圖
對旅程的作用

提案 C

參與階梯：讓「加 LINE」成為旅程的第二步

概念
以品牌宣言開場，接著用四階段階梯（讀文章 → 加 LINE → ESG共學坊 → 會員／顧問）告訴訪客「你在這裡」，加 LINE 那一階放大成主要行動卡，前後兩階提供退路與下一步。
參考來源
Patagonia Action Works 的分級參與、B Lab 的運動宣言；本專案標竿研究建議的「讀文章（0 成本）→ 加 LINE（低）→ ESG共學坊（中）→ 會員／諮詢（高）」四階卡片。
優點
  • 把 /join 與全站旅程串起來，說清楚加入後還能做什麼
  • 宣言與數字讓頁面有品牌溫度
  • 「你在這裡」降低承諾感：只是第二步，不是簽約
風險
  • 資訊比 A 多，偏離「單一目標」的極簡原則
  • 階梯中的其他連結可能分散點擊
  • 宣言文案需客戶認可
對旅程的作用
給第一次來、還在評估的人一張全貌地圖，讓加 LINE 顯得自然、低門檻；同時把已加入的人往ESG共學坊與會員方案推進一步。
