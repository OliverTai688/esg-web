最新文章：新聞室列表 三案

旅程位置：認識（最新觀點）。主要角色 P5 政府／學校／論壇主辦／媒體、P2 大企業窗口：他們想快速判斷「這個團隊最近在做什麼、是否活躍」。

與 /learning 的分工：/learning 依主題、教你從哪裡開始；/insights 依時間、告訴你最近發生什麼。三案都刻意不用主題書架、不放「從這裡開始」，避免兩條路由長得一樣。

現況兩頁共用 content/posts/ 且版面幾乎相同（精選大卡＋卡片格線），是客戶覺得「重複」的來源。三案的精選都不是「訂閱 3 步驟」公告（L02）。注意：最新一篇是 2024.11.11，時間序版面會直接曝露更新頻率，上線前建議補 2025–2026 的活動回顧或公告。

提案 A

時間序新聞室：日期是主角

概念
像企業新聞室一樣，以「年 · 月」分段、日期大字排列，每則標示類型（觀點／專訪／調查報告／公告）。最新一則以無圖的頭條呈現；側欄放類型統計、媒體窗口與 RSS，並把想深入某主題的人送回共好學習。
參考來源
Schneider Electric 與 Ørsted 的 Newsroom（日期＋類型標籤＋媒體聯絡窗口）；South Pole 的新聞與報告發布頁。
優點
  • 與 /learning 差異最明確，一眼就是「新聞室」
  • 媒體窗口與 RSS 直接服務 P5
  • 每則附「在共好學習延伸閱讀」，兩頁互相導流而不重複
風險
  • 內容停在 2024 年，時間軸會讓「不活躍」更明顯
  • 需要新增 type 欄位（觀點／專訪／調查報告／公告／活動回顧）
  • 文章少時月份段落顯得稀疏
對旅程的作用
讓 P5、P2 在 10 秒內確認「這個團隊持續在產出」，並提供明確的邀約管道（mailto＋LINE）；想深入的人被導回 /learning 依主題延伸閱讀。

提案 B

季刊雜誌：把文章編成一期一期

概念
以「共好觀點」為刊名，按季度編排：封面故事用一句真實引言做成海報，本季文章用馬賽克版面，再穿插「觀點引言」與數據金句；過去的季度收進過刊。沒有照片也能有雜誌感——每個主題一款 CSS 紋樣封面。
參考來源
Patagonia Stories 的編輯式版面與大引言；Natura &Co 網頁版年報與 IKEA highlights 的「一期一報」節奏。
優點
  • 品牌感最強，最能展現「有觀點的顧問」
  • 引言與數據金句讓 P2、P5 快速掌握立場
  • 季度節奏給團隊固定的內容產出目標
風險
  • 需要持續編輯（每季選封面、寫引言），人力不足時最容易荒廢
  • 一季文章太少時版面會空
  • 視覺較重，需注意手機載入與閱讀效率
對旅程的作用
把散落的文章包裝成「有立場的出版品」，強化信任階段的專業形象；封面故事與引言是對外分享（社群、提案簡報）最好用的素材，文末以 LINE 留住讀者。

提案 C

精簡清單：像更新紀錄一樣好掃

概念
不放精選、不放封面：一張依日期排列的表格（日期｜類型｜標題｜主題與閱讀時間），上方用類型頁籤篩選。手機上自動變成兩行式列表。右側只有訂閱（LINE、RSS）與媒體窗口。
參考來源
South Pole 與 B Lab 的新聞／更新列表、GOV.UK 式的高密度清單；Delta 歷年報告的固定命名與完整列表。
優點
  • 最輕、最快，維護成本最低
  • 誠實呈現「全部 16 篇、最近更新日期」
  • 與 /learning 的卡片視覺完全不同，不會被誤認是同一頁
風險
  • 缺少情緒與品牌感，第一次來的人不會被吸引往下讀
  • 標題寫得不好時，列表會變得乾
  • 「最近更新 2024.11.11」若不持續更新，反而是負面訊號
對旅程的作用
定位為「檔案室」：服務已經知道 CO-ESG、要找特定文章或確認近況的 P2／P5；把吸引新訪客的工作完全交給 /learning，兩頁職責切得最乾淨。
