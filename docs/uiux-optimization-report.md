## 三、逐頁 UI/UX 優化建議

---

### 頁面 1：首頁 (`/[locale]`)

#### 現狀
- 7 個完整區塊：Hero → 品牌故事 → 痛點與解方 → 影響力數據 → 未來服務 → 信任背書 → CTA
- Hero 使用 Vanta.js 3D 霧面動態背景 + BlurIn 文字動畫
- 影響力數據使用 NumberTicker 動畫計數器
- 長頁面，資訊量大

#### 優化方向

| 項目 | 優先級 | 說明 |
|------|--------|------|
| Hero CTA 可見性 | 🔴 高 | 確認 CTA 按鈕在 Vanta 動態背景上的對比度是否足夠，尤其在行動裝置上 |
| 首屏載入速度 | 🔴 高 | Vanta.js + Three.js 體積大（~500KB），考慮在低階裝置或行動裝置降級為靜態漸層背景 |
| 故事區塊可讀性 | 🟡 中 | 摺疊式完整故事可能被忽略，考慮改用 timeline 或 stepper 視覺呈現 |
| 影響力數據區排版 | 🟡 中 | EvidenceCard 以格線呈現，確認在平板斷點（768px–1024px）的卡片排列是否合理 |
| 信任背書區 | 🟡 中 | 目前為推薦語卡片，可加入合作企業 Logo 牆增強說服力 |
| 頁面內導覽 | 🟢 低 | 頁面較長（7 區塊），可考慮加入 scroll spy 側邊導覽或回到頂端按鈕 |
| 動畫效能 | 🟢 低 | SectionEntrance 動畫如過多可能在低階裝置造成卡頓，考慮 `prefers-reduced-motion` 支援 |

### 頁面 3：活動課程 (`/[locale]/events`)

#### 現狀

## 四、跨頁面共通議題

### 4.1 效能

| 議題 | 嚴重度 | 說明 |
|------|--------|------|
| Three.js 包大小 | 🔴 高 | Vanta.js 依賴 Three.js（~500KB），僅用於首頁 Hero 背景，應確認已做 code splitting / dynamic import |
| 圖片最佳化 | 🟡 中 | 確認所有文章封面圖、Logo 等是否使用 Next.js Image 元件並設定適當尺寸 |
| 字型載入 | 🟡 中 | Geist 字型確認使用 `next/font` 的 subset 載入，避免 FOIT/FOUT |

### 4.2 無障礙（Accessibility）

| 議題 | 嚴重度 | 說明 |
|------|--------|------|
| 色彩對比度 | 🔴 高 | oklch 色彩系統中的 accent 色在白底上需驗證 WCAG AA 對比度（4.5:1） |
| 鍵盤導覽 | 🟡 中 | 確認所有互動元素（漢堡選單、FAQ 摺疊、語言切換）支援鍵盤操作 |
| ARIA 標籤 | 🟡 中 | 動態元件（Collapsible, 行動選單）需完整 ARIA 屬性 |
| prefers-reduced-motion | 🟢 低 | Framer Motion 動畫應尊重使用者的減少動態偏好設定 |

### 4.3 SEO 與社群分享

| 議題 | 嚴重度 | 說明 |
|------|--------|------|
| OpenGraph 圖片 | 🟡 中 | 各頁面是否有獨立的 OG 圖片，而非僅用預設圖 |
| 結構化資料 | 🟡 中 | 文章頁可加入 Article schema，課程頁可加入 Course/Event schema |
| robots.ts / sitemap.ts | 🟢 低 | 已存在，確認動態頁面（文章、課程）是否完整列入 sitemap |

### 4.4 國際化（i18n）

| 議題 | 嚴重度 | 說明 |
|------|--------|------|
| Consulting 頁硬編碼 | 🔴 高 | 服務卡片的標題、價格、描述仍為中文硬編碼，未接入字典 |
| Events 資料 i18n | 🟡 中 | `courses.ts` 課程資料為中文硬編碼，英文版會顯示中文內容 |
| 語言切換體驗 | 🟢 低 | 切換語言時是否保持當前頁面位置，避免跳回頁頂 |
